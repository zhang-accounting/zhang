## 介绍

Amazon S3 以及兼容 S3 协议的对象存储（MinIO、Cloudflare R2、阿里云 OSS、腾讯云 COS、Backblaze B2 等）价格低廉、可靠且易于获取。张记账可以直接从存储桶中读写账本文件，这样服务本身可以无状态运行（例如运行在容器中），数据则保存在对象存储里。

## 配置要求

| 参数 | 命令行参数 | 环境变量 | 必填 | 示例值 | 备注 |
|----|-------|------|----|-----|----|
| 数据源 | source | ZHANG_DATA_SOURCE | 是 | `s3` | 标识 S3 为数据源。 |
| 存储桶 | N/A | ZHANG_S3_BUCKET | 是 | `my-ledger` | 存放账本文件的存储桶。 |
| 根目录 | N/A | ZHANG_S3_ROOT | 否 | `/accounting` | 账本在存储桶中的前缀，默认为 `/`。 |
| 服务地址 | N/A | ZHANG_S3_ENDPOINT | 否 | `https://<account_id>.r2.cloudflarestorage.com` | 使用兼容 S3 的服务时必填，默认为 `https://s3.amazonaws.com`。 |
| 区域 | N/A | ZHANG_S3_REGION | 否 | `us-east-1` | 未设置时读取 `AWS_REGION`。签名需要区域信息，Cloudflare R2 可使用 `auto`，MinIO 可使用 `us-east-1`。 |
| Access Key ID | N/A | ZHANG_S3_ACCESS_KEY_ID | 否 | `AKIA...` | 未设置时使用标准 AWS 凭证链（`AWS_ACCESS_KEY_ID`、`~/.aws/credentials` 等）。 |
| Secret Access Key | N/A | ZHANG_S3_SECRET_ACCESS_KEY | 否 | `your_secret` | 未设置时使用标准 AWS 凭证链。 |
| Session Token | N/A | ZHANG_S3_SESSION_TOKEN | 否 | `your_session_token` | 仅在使用临时凭证时需要。 |
| 虚拟主机风格 | N/A | ZHANG_S3_VIRTUAL_HOST_STYLE | 否 | `true` | 使用 `https://<bucket>.<endpoint>` 而不是路径风格 `https://<endpoint>/<bucket>`，阿里云 OSS 等服务需要开启。 |

使用 S3 时 `zhang serve` 的 `path` 参数会被忽略，账本根目录由 `ZHANG_S3_ROOT` 决定；主文件仍由 `--endpoint` 指定（默认为 `main.zhang`）。

## 设置步骤

1. **创建存储桶**，并将账本文件（如 `main.zhang`）上传到存储桶中，也可以放在 `accounting/` 之类的前缀下。
2. **创建访问凭证**，确保其对该存储桶拥有 `GetObject`、`PutObject` 和 `ListBucket` 权限。
3. **配置环境变量**并启动张记账：

```shell
ZHANG_DATA_SOURCE=s3 \
ZHANG_S3_BUCKET=my-ledger \
ZHANG_S3_ROOT=/accounting \
ZHANG_S3_REGION=us-east-1 \
ZHANG_S3_ACCESS_KEY_ID=your_access_key \
ZHANG_S3_SECRET_ACCESS_KEY=your_secret \
zhang serve /accounting --endpoint main.zhang
```

### Docker

```shell
docker run --name zhang -d -p 18000:8000 \
  -e ZHANG_DATA_SOURCE=s3 \
  -e ZHANG_S3_BUCKET=my-ledger \
  -e ZHANG_S3_ENDPOINT=https://<account_id>.r2.cloudflarestorage.com \
  -e ZHANG_S3_REGION=auto \
  -e ZHANG_S3_ACCESS_KEY_ID=your_access_key \
  -e ZHANG_S3_SECRET_ACCESS_KEY=your_secret \
  kilerd/zhang:latest
```

## 故障排除

- **`region is missing`**：设置 `ZHANG_S3_REGION`（或 `AWS_REGION`）。对于不关心区域的兼容服务，通常使用 `us-east-1` 或 `auto` 即可。
- **访问被拒绝**：确认凭证对存储桶及对应前缀拥有读、写和列举权限。
- **读取不到文件**：检查 `ZHANG_S3_ROOT` 与 `--endpoint`，主文件会从存储桶内的 `<ZHANG_S3_ROOT>/<endpoint>` 读取。
